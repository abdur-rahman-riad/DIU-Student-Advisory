# Student Advisory System

A browser-based student advisory dashboard for Daffodil International University (DIU). Advisors can look up students by ID, review academic and financial records, and get AI-powered insights through a built-in chat interface.

## Features

- **Student Lookup** — Search by student ID or name with instant results
- **Quick Access** — Pin frequently viewed student IDs as one-click chips (removable)
- **Academic Overview** — CGPA, SGPA trend, completed credits, semester-wise course results
- **Payment Summary** — Total payable, paid amount, due balance with visual progress bar
- **Guardian Info** — Father and mother contact details
- **Issue Flags** — Automatically highlights low CGPA, high dues, and attendance issues
- **AI Chat** — Ask questions about the loaded student's record via a Gemini-powered backend
